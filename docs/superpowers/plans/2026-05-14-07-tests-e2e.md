## Patrón estándar por endpoint

Para CADA endpoint (Create / Update / Delete / Get / List / acciones especiales):

### Caminos a cubrir (cap. 09)

| HTTP | Caso |
|---|---|
| 2xx | Camino feliz |
| 400 | Payload inválido (ID mal formado, campo requerido vacío) |
| 404 | Recurso no existe (sólo para PUT/DELETE/GET por ID) |
| 409 | Invariante violada (nombre duplicado, transición no válida) |
| 403 | Usuario sin permiso (sólo donde aplique) |

### Estructura del Cest

```php
<?php

declare(strict_types=1);

namespace App\Tests\Api\<Aggregate>;

use App\Tests\Support\ApiTester;
use Codeception\Util\HttpCode;
use App\Shared\Domain\Model\ErrorCode;

final class Create<Aggregate>Cest
{
    public function _before(ApiTester $I): void
    {
        $I->haveAdminHttpHeaders();
    }

    public function create<Aggregate>Successfully(ApiTester $I): void
    {
        $I->wantTo('create a <aggregate> with valid data');

        $I->sendPost('/<aggregates>', [
            'id' => '11111111-1111-4111-8111-111111111111',
            'name' => 'Acme',
            // ...
        ]);

        $I->seeResponseCodeIs(HttpCode::CREATED);
    }

    public function create<Aggregate>WithInvalidId(ApiTester $I): void
    {
        $I->wantTo('reject a <aggregate> with invalid id');

        $I->sendPost('/<aggregates>', ['id' => 'not-a-uuid', 'name' => 'Acme']);

        $I->seeResponseCodeIs(HttpCode::BAD_REQUEST);
        $I->seeResponseIsJson();
        $I->seeResponseErrorCodeContent(ErrorCode::INVALID_<AGGREGATE>_ID->value);
    }

    public function create<Aggregate>WithDuplicatedName(ApiTester $I): void
    {
        $I->wantTo('reject a duplicated <aggregate> name');

        $I->with<Aggregate>(name: 'Acme');

        $I->sendPost('/<aggregates>', [
            'id' => '22222222-2222-4222-8222-222222222222',
            'name' => 'Acme',
        ]);

        $I->seeResponseCodeIs(HttpCode::CONFLICT);
        $I->seeResponseErrorCodeContent(ErrorCode::DUPLICATED_<AGGREGATE>_NAME->value);
    }

    public function create<Aggregate>WithoutAdmin(ApiTester $I): void
    {
        $I->haveEmployeeHttpHeaders();
        $I->sendPost('/<aggregates>', ['id' => '...', 'name' => 'Acme']);
        $I->seeResponseCodeIs(HttpCode::FORBIDDEN);
        $I->seeResponseErrorCodeContent(ErrorCode::FORBIDDEN->value);
    }
}
```

- `seeResponseErrorCodeContent(string $code)` — comprueba `code` en el JSON

### Helpers que añade Plan 7:

```php
// En tests/Support/ApiTester.php

public function haveEmployeeHttpHeaders(string $language = 'es'): void
{
    $this->haveHttpHeader('Content-Type', 'application/json');
    $this->haveHttpHeader('Api-Language', $language);
    $jwt = $this->createTestJwt(role: \App\Shared\Domain\Enum\SystemRole::EMPLOYEE);
    $this->amBearerAuthenticated($jwt);
}

private function createTestJwt(\App\Shared\Domain\Enum\SystemRole $role): string
{
    // Implementación: usar JWTTokenManagerInterface del container para emitir un JWT firmado válido
    // para un User fixture (admin o employee).
    /** @var \Lexik\Bundle\JWTAuthenticationBundle\Services\JWTTokenManagerInterface $manager */
    $manager = $this->grabService('lexik_jwt_authentication.jwt_manager');
    $user = $this->grabRepository(\App\Core\Domain\Model\Aggregate\User::class)
        ->findOneByRole($role);
    return $manager->create($user);
}

// Helpers per-aggregate (uno por agregate):

public function withUser(?string $userId = null, ?string $email = null, ?\App\Shared\Domain\Enum\SystemRole $role = null): \App\Core\Domain\Model\Aggregate\User
{
    $user = \App\Tests\Unit\Core\Domain\Mother\User\UserMother::create(
        id: $userId ? new \App\Core\Domain\Model\VO\User\UserId($userId) : null,
        email: $email ? new \App\Core\Domain\Model\VO\Common\Email($email) : null,
        role: $role,
    );
    $this->grabService(\App\Core\Domain\Model\Repository\UserRepository::class)->add($user);
    $this->grabService(\Doctrine\ORM\EntityManagerInterface::class)->flush();
    return $user;
}

public function withSector(?string $sectorId = null, ?string $name = null): \App\Core\Domain\Model\Aggregate\Sector

    );
    $this->grabService(\App\Core\Domain\Model\Repository\SectorRepository::class)->add($sector);
    $this->grabService(\Doctrine\ORM\EntityManagerInterface::class)->flush();
    return $sector;
}
```

## Configuración Codeception común

### `codeception.yml` (ya existe del Plan 1)

Asegurar que la suite `Api` tiene:

```yaml
modules:
    enabled:
        - REST:
            url: http://localhost
            depends: Symfony
        - Symfony:
            app_path: 'src'
            environment: 'test'
        - Doctrine:
            depends: Symfony
            cleanup: true       # rollback transactional por test
        - \App\Tests\Support\Helper\Api
```

### Migration extension

Añadir a `tests/Api.suite.yml`:

```yaml
extensions:
    enabled:
        - App\Tests\Support\Extension\DbMigrationExtension
```

Crear `tests/Support/Extension/DbMigrationExtension.php`:

```php
<?php

declare(strict_types=1);

namespace App\Tests\Support\Extension;

use Codeception\Event\SuiteEvent;
use Codeception\Events;
use Codeception\Extension;

final class DbMigrationExtension extends Extension
{
    public static array $events = [
        Events::SUITE_BEFORE => 'beforeSuite',
    ];

    public function beforeSuite(SuiteEvent $event): void
    {
        if ($event->getSuite()->getName() !== 'Api') {
            return;
        }
        passthru('php bin/console doctrine:migrations:migrate --no-interaction --env=test', $exit);
        if ($exit !== 0) {
            throw new \RuntimeException('Migrations failed');
        }
    }
}
```
